ARCHITECTURE (Command Automaton)
----------------------------------
Single useReducer in App.tsx. All state changes go through one door:

  Event → Command → applyCommand(state, cmd) → new State

Commands are a discriminated union in src/state/ModelState.ts:
  insertNode | deleteNode | insertArc | deleteArc | moveNode
  setView | selectNode | selectArc | groupNodes | convertLeafToComposite | reset

New commands added by extending Command union + applyCommand switch case.

MODULES
-------
src/state/ModelState.ts      — AppState, Command, applyCommand reducer
src/model/ModelGraph.ts      — ModelGraphOps (insert/delete node/arc, arc counter)
src/tree/Tree.ts             — TreeOps (addChild, removeNode, moveID, getAncestors, getSiblings)
src/tree/computeGraphView.ts — Compute visible nodes/arcs from tree + model + layout
src/types/hierarchy.ts     — TypeScript interfaces for all three layers
